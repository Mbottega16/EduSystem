How to Import Your Canva Generations into EduSystem:

  1. Generate in Canva: Paste any prompt into Canva's Magic Media / Text-to-Image app. Keep aspect ratio as 1:1 Square.
  2. Download from Canva: Save your images as PNG.
  3. Drop into the Game Folder: Move the downloaded PNGs into shots/canva_imports/ in the EduSystem directory. Name the file after the Item ID (e.g. rug_alphabet_circle.png).
  4. One-Click Conform: Run Import Canva Art.bat (or python tools/canva_art_pipeline.py --import). This automatically:
    • Strips the magenta background into transparent PNG.
    • Snaps every pixel to the 192 authentic LimeZu palette tones.
    • Applies the signature 1px #3a3a50 cool slate keyline.
    • Doubles the sprite to 2x resolution and registers it into the game engine!
