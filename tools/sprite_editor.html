🎨 Colour
🌫 Soften

Blends each drawn pixel toward its neighbours' average — a hard colour edge becomes a short hand-drawn gradient instead of a flat step. Never touches transparent pixels.

🧹 Flatten
tolerance 45

Click a pixel and every pixel close enough in colour anywhere in the frame collapses to one shared average. Gathers "all the blue, but not the red".

🌈 Retint
±24° hue

Recolours a whole shaded region at once and keeps the shading. Click a blue shirt's mid-tone with green picked: the dark fold and the light highlight both become the matching shades of green, because only the HUE moves and each pixel keeps its own lightness. Near-greyscale pixels are never touched, so outlines stay put. This is what makes variants practical.

⬇ Load

💾 Export

Saves <name>.png. Put it in art/, then run the import — godot --headless --path . --import — because a PNG on disk is not a texture Godot can load until it has been imported. To have children born with it, add the name to ART in scripts/data/names.gd.

For a whole new character rather than a one-off, use Make a Sprite.bat instead: characters here are palettes, and that tool writes the palette, draws the sheet, imports it and registers the name for you.
